# Abhigyan Das — Portfolio Website

## Files
- `index.html` — complete responsive portfolio website. No build step or dependencies required.

## Publish with GitHub Pages
1. Go to your repository **Settings**.
2. In the left sidebar, click **Pages**.
3. Under **Build and deployment**:
   - Select **Deploy from a branch**
   - Choose branch: **main**
   - Choose folder: **/ (root)**
4. Click **Save**.

Your website URL:
`https://abhigyandas52-bit.github.io/Abhigyan_Portfolio/`

## Publish with Netlify
Create a new site and drag/drop this folder (or the `index.html` file) into Netlify's deploy area.

## Publish with Vercel
Import the folder/repository as a new project. No framework or build command is required.

## Notes
This version is intentionally dependency-free so it can be hosted almost anywhere.
